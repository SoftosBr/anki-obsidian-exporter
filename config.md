# Anki Obsidian Exporter

`default_export_folder`
: Optional folder opened by default in the export dialog. Leave empty to choose manually each time.

`default_file_name`
: Default Markdown file name used in the export dialog. The add-on appends `.md` when needed.

`deck_settings`
: Local per-deck settings saved automatically after a successful export. Decks without saved settings use `default_export_folder` and `default_file_name`.
